# site-casamento

Sistema web desenvolvido para gerenciamento e organização de casamento, com foco em praticidade, experiência do usuário e responsividade.

O projeto centraliza informações do evento em uma única plataforma, permitindo confirmação de presença, localização da cerimônia, lista de presentes e gerenciamento administrativo dos convidados.

Projeto hospedado em produção com domínio próprio: [davifernanda.com](https://davifernanda.com/)

## Funcionalidades

- Página com informações do evento
- Localização da cerimônia e recepção
- Lista de presentes personalizada
- Sistema de confirmação de presença (RSVP)
- Validação automática de convidados cadastrados
- Layout responsivo para dispositivos móveis
- Área administrativa exclusiva (`/adm`)
- Controle de convidados confirmados e pendentes
- Visualização de presentes recebidos

## Sistema de confirmação de presença

O formulário de RSVP realiza uma validação automática do nome informado, verificando se o convidado está previamente cadastrado na lista de convidados.

Isso permite maior controle das confirmações e evita registros indevidos.

## Área administrativa

O sistema possui uma área administrativa onde os noivos podem:

- acompanhar convidados confirmados;
- visualizar quem ainda não confirmou presença;
- acompanhar os presentes recebidos;
- gerenciar informações do evento.

## Objetivo do projeto

O objetivo do projeto foi criar uma plataforma personalizada para casamento que unisse organização, praticidade e boa experiência para os convidados.

O sistema foi utilizado em um evento real e desenvolvido com foco em simplicidade, desempenho e usabilidade.
